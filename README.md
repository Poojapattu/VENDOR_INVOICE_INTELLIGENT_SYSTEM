Invoice Intelligence System 🚚📊

An AI-powered Invoice Intelligence System built using Python, Machine Learning, Streamlit, SQL concepts, and Data Analytics to predict freight costs and detect high-risk invoices automatically.

🚀 Project Overview

The Invoice Intelligence System helps businesses analyze invoice data intelligently by:

Predicting freight/shipping costs
Detecting risky or anomalous invoices
Performing invoice analytics
Supporting data-driven decision making

This project combines:

Machine Learning
Anomaly Detection
